Monochrome icon glyph — the single way to render iconography in UP.PRO.

```jsx
<Icon name="footprints" size={22} color="var(--lime-500)" />
```

Fetches the Lucide static SVG once per slug and inlines it, so the glyph is a real stroked `<svg>` that takes any colour and captures cleanly. Common slugs in this product: `footprints`, `flame`, `droplet`, `moon`, `timer`, `trophy`, `bookmark`, `chevron-right`, `arrow-left`, `arrow-right`, `plus`, `bar-chart-3`, `utensils`, `house`, `settings`, `bell`, `search`, `sliders-horizontal`, `arrow-up-down`, `play`, `pause`, `check`.
